## 1. IO / 文件格式（v8.0 分册 06）

### 1.1 规格 chunk 处置表（`docs/ase-file-specs.md` 全量 chunk）

| Chunk | 规格 | `pxl-ase-io` 现状 | 缺口 |
|---|---|---|---|
| Header(128B) | magic/帧数/尺寸/色深/flags/**pixel ratio**/透明索引/色数/grid | 读；`_flags`/`_px_w/_px_h` 读取后**丢弃**（read.rs:43-52） | `pixel_ratio` 模型无字段（`doc/pixel_ratio.h`）；header flags 位语义（layer opacity 有效 / 组合成 / UUID）未建模 |
| Frame header | old/new chunk 计数 | 已正确处理（read.rs:85-94） | 无 |
| Old palette 0x0004/0x0011 | 有新板时忽略 | 已正确（saw_new_palette） | 无 |
| Layer 0x2004 | flags 位 1/2/4/8/**16/32/64**；type 0/1/**2**；blend 19 种；UUID | 读；`LayerFlags` 只建模 visible/editable/**background**（layer.rs:34-47） | 位 4 锁移动、16 链接偏好、32 折叠、64 参考层缺失；UUID（header bit4）丢弃 |
| Cel 0x2005 | type 0/1/2/3；**Z-Index** | 读；z_index 存入（read.rs:187） | **渲染未消费 z_index**（见 §2.1） |
| **Cel Extra 0x2006** | 精确 bounds / 缩放 | **跳过**（落入 unknown 分支） | 缺口：读取后至少透传，写回不丢 |
| **Color Profile 0x2007** | sRGB/ICC/gamma | **跳过** | 缺口：至少透传字节；v8.0 02 已声明完整 ICC 非目标，透传 ≠ 色彩管理 |
| **External Files 0x2008** | 外部 palette/tileset/扩展 ID | **跳过** | 缺口：与 Tileset chunk 联动；最小动作是透传 |
| Mask 0x2016 (DEPRECATED) | — | 跳过 | `确认`（规格标注废弃） |
| Path 0x2017 | 从未使用 | 跳过 | `确认` |
| Tags 0x2018 | 方向 0-3 / repeat / 颜色 | 读；**颜色读入后丢弃**（read.rs:258-259） | tag 颜色存 `user_data` 语义（规格：颜色在 tags chunk 后的 user data chunk） |
| Palette 0x2019 | 帧 palette 变更 / 条目名 | 读首个；**条目名丢弃**（read.rs:289） | 帧级 palette（`doc/palette.h` 支持按帧）未建模；条目名透传缺失 |
| **User Data 0x2020** | text/color/**properties map**（扩展属性系统） | **跳过** | 缺口：至少读存 text/color 写回；properties map（嵌套类型 0x0001-0x0013）可分期 |
| Slice 0x2022 | keys / 9-patch / pivot | 读（center+pivot 齐全） | 无 |
| **Tileset 0x2023** | tile 图集 / base index / flip flags | **跳过** | 见 §6 tilemap 冻结 |

**增补任务（GA）**：

| # | 任务 | 优先级 | 验收 |
|---|---|---|---|
| GA-1 | User Data chunk 读写（text/color），挂到 layer/cel/tag/slice；properties map 可先 `raw bytes` 透传 | P0 | 含 tag 颜色的 fixture roundtrip 不丢 |
| GA-2 | Color Profile chunk 透传（读→存→写回原字节）；不做 ICC 解析 | P1 | roundtrip 字节保留 |
| GA-3 | Cel Extra 读取存模型字段（精确 bounds）；渲染可用或忽略但写回保留 | P1 | 同上 |
| GA-4 | Header/Layer 位语义补全 + UUID + pixel ratio 字段 | P1 | `doc/pixel_ratio.h` 语义对照 |
| GA-5 | External Files chunk 透传 | P2 | 有外部引用文件时可读 |
| GA-6 | 写回警告机制：编码器丢弃任何读入字段时输出 stderr warning（防静默数据丢失） | P0 | 丢 tag 颜色文件触发警告 |

```text
GC-1 矩阵补行（纯文档，先恢复诚实基线）
 └─ GA-1/GA-6 User Data + 写回警告（数据保真 P0）
```
