> 日期：2026-11-02（Asia/Shanghai）

## 1. 背景

Aseprite 的可编辑对象不是「一张 PNG」，而是 **Sprite**：画布尺寸 + 色模式 + 层树 + 帧序列 + 每层每帧的 Cel（可链接）+ Palette + Tags + Slices + Grid/Tileset 等。无头 CLI 要对齐批处理，必须先有等价文档模型，否则 `--layer` / `--tag` / `--split-slices` 无法定义语义。

现有 PixelGames 模型：

- `pxl-core::IndexFrame` + `Palette`：单帧索引图；
- `pxl-format::PxlDoc` / `Anim` / `Recipe`：面向生成与编译的文档，**不是**多层时间轴编辑文档；
- `pxl-format::SpriteSpec`：源规格，不是运行时 Sprite 对象图。

因此需要新建 `pxl-ase-doc`（名见 00），再桥到 `PxlDoc`。

## 2. Aseprite 对应模块（路径）

以下均相对 `thirdparty/aseprite/src/doc/`（本地 `ls` 核实）：

| 概念 | 代表文件 | 备注 |
|---|---|---|
| ColorMode | `color_mode.h` | `RGB` / `GRAYSCALE` / `INDEXED` / `BITMAP` / `TILEMAP` |
| Sprite | `sprite.h` | 根对象；持有层、帧时长、palette、tags… |
| Document | `document.h` | 文档容器（可含 sprite） |
| Layer / LayerGroup / LayerImage | `layer.h` | 组与图像层；tilemap 见 `layer_tilemap.h` |
| Cel / CelData | `cel.h`、`cel_data.h` | 帧×层上的图像引用；支持链接 |
| Image | `image.h`、`image_spec.h` | 像素缓冲 |
| Palette | `palette.h`、`palette_io.h` | 调色板 |
| Remap / RgbMap | `remap.h`、`rgbmap*.h` | 索引重映射 / 最近色 |
| Tag / Tags | `tag.h`、`tags.h` | 帧标签（动画区间） |
| Slice / Slices | `slice.h`、`slices.h` | 切片（含 keys/bounds/pivot） |
| Grid | `grid.h` | 网格 |
| Mask / selection | `mask.h`、`selected_layers.h` | 选区；CLI 无头可用矩形/色键子集 |
| BlendMode | `blend_mode.h` | NORMAL…DIVIDE 等 |
| Tileset | `tileset.h`、`tilesets.h` | 与 tilemap 层配合；`--export-tileset` |
| Algorithm helpers | `algorithm/`（flip、floodfill、rotsprite、resize…） | 实现落到 03，模型只暴露能力边界 |
| Palette files | `file/gpl_file.*` 等 | IO 见 02/06 |

色模式字节宽度（`color_mode.h`）：RGB=4，Grayscale=2，Indexed=1。

## 3. 目标

1. 定义 Rust 类型：`AseDoc` / `Sprite` / `Layer` / `Cel` / `FrameTiming` / `Palette` / `Tag` / `Slice` / `Grid`。  
2. 三种主色模：`Rgba` / `Indexed` / `Grayscale`（BITMAP/TILEMAP 标为后续）。  
3. 层树：图像层 + 组；可见性/锁定/不透明度/混合模式字段预留。  
4. Cel：`(layer_id, frame_index) → image_ref`；**linked cel** 共享像素缓冲。  
5. 与 `pxl-core::IndexFrame` 的双向桥（至少 Indexed → IndexFrame）。  
6. 不变量与校验错误码（空层、断链、色模不一致等）。

## 4. 非目标

- 完整 undo 图（`src/undo/`）与可观察信号（`observable`）。  
- UI 用的 site/active 层（`app/active_site_handler.*`）。  
- 压力笔刷会话状态、自定义 brush 位图资源库。  
- 一等公民完整 TILEMAP 编辑（可读字段可先存 raw，命令面后置）。

## 5. 与 steps 对照表

| 能力 | 标注 | 证据 |
|---|---|---|
| 单帧索引缓冲、bbox、stats | 【已有·可复用】 | `pxl-core/src/frame.rs`：`IndexFrame`、`Rect`、`FrameStats` |
| 调色板 ≤256、文本 ≤62 | 【已有·可复用】【部分】 | `pxl-core/src/palette.rs`、`lib.rs` `MAX_TEXT_COLORS`；Aseprite 索引模式常用 256 |
| 文档 `PxlDoc`/`Anim` | 【部分】 | `pxl-format/src/model.rs`：有帧名与 duration，**无**层树/Cel/Slice |
| Recipe/SpriteSpec | 【部分】 | `recipe.rs`/`sprite.rs`：规格侧；非编辑文档 |
| Layer/Cel/Tag/Slice/Grid 一等模型 | 【缺失】 | 无对应 crate 类型 |
| BlendMode 合成字段 | 【缺失】 | 见 05；模型需预留 enum |

## 6. 工作包 / 里程碑

### M1.0 — 类型草图与不变量

- 冻结 ID 类型（`LayerId`、`CelId`、`ImageId`）、色模 enum、错误码。  
- 文档化与公开规格字段的映射表（写入 sources 附录或本文件附录）。  
- **验收**：设计评审合并进 plan；代码阶段有单元测试骨架。未跑测 = `NOT_ASSESSED`。

### M1.1 — 内存模型实现

- Arena 或槽位存储 Image；Cel 引用计数或 `Arc` 实现 linked。  
- Layer 树插入/删除/重排 API（纯库，无 CLI）。  
- **验收**：构造「2 层 × 3 帧、其中 2 cel 链接」的内存样例；序列化到测试用 JSON 中间态（非 `.aseprite`）。

### M1.2 — 与 `pxl-core` 桥

- `Indexed` 层帧 → `IndexFrame`；反向从 `IndexFrame`+`Palette` 建单层 Sprite。  
- **验收**：往返后像素 hash 一致（复用 `IndexFrame::hash_bytes`）。

### M1.3 — Tag / Slice / Grid 最小结构

- Tag：`name, from, to, direction, repeat`。  
- Slice：`name` + keys(`frame, bounds, center?, pivot?`)。  
- Grid：origin + size。  
- **验收**：与 07、公开 `--list-tags`/`--list-slices` JSON 形状对照表完成。

### M1.4 — 色模转换占位 API

- API 签名预留；真正算法在 02/05。  
- **验收**：调用未实现时返回明确 `E_NYI`，不静默。

## 7. 建议 Rust 形状（示意，非最终）

```rust
pub enum ColorMode { Rgba, Grayscale, Indexed }
pub struct Sprite {
    pub width: u16,
    pub height: u16,
    pub mode: ColorMode,
    pub layers: LayerTree,
    pub frame_durations_ms: Vec<u32>,
    pub palette: Option<Palette>,
    pub tags: Vec<Tag>,
    pub slices: Vec<Slice>,
    pub grid: Option<Grid>,
}
```

字段名可在实现时调整；验收看语义而非标识符拼写。

## 8. 验收总则

- 库 crate 可 `cargo test`（独立 target）；覆盖：链接 cel、层可见性过滤、空文档拒绝导出。  
- 无 UI 依赖、无窗口 crate。  
- 禁止从 `thirdparty/aseprite/src/doc/*.cpp` 粘贴逻辑。
