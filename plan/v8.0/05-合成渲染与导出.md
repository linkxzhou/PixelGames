# 05 · 合成渲染与导出

> 日期：2026-11-02（Asia/Shanghai）  
> 状态：**部分完成**（2026-11-02 Asia/Shanghai）  
> 证据：`render::flatten_frame_rgba`；`ase convert`/`ase sheet`
> Aseprite 对应：`src/render/`（MIT LICENSE 本地存在）；导出行为对齐公开 CLI `--sheet`/`--save-as`/`--data`/`--trim*`…  
> steps：`pxl-export`、`step-300 sheet`/`render`

## 1. 背景

无头最值钱的能力之一是：**按层可见性与混合模式把 Sprite 合成出来**，再导出 PNG 序列、GIF、spritesheet + JSON。现有 `pxl-export` 已能把**已经是平面帧列表**的 `IndexFrame` 打成 sheet，并写出 **Aseprite hash 风格** JSON（`frames` + `meta.frameTags`，`meta.app = "pxl"`）。缺的是从多层 `AseDoc` **渲染**出那些平面帧。

## 3. 目标

1. `flatten_frame(sprite, frame_i, layer_filter) → RgbaImage`（再可选转 Indexed）。  
2. 支持 `BlendMode` 子集：至少 `NORMAL`；P1 加 `MULTIPLY`/`SCREEN`/`OVERLAY` 等常用。  
3. 导出：  
   - PNG 序列 / 单帧；  
   - GIF；  
   - spritesheet + JSON（**兼容**现有 `pxl-export::sheet_json` 消费者，并逐步补 `json-array`）。  
4. trim/crop/padding/extrude/scale 与公开语义对齐（测用例级）。  
5. 明确与 `step-300 sheet` 分工。

## 4. 非目标

- 编辑器内实时渲染器切换（devmode F1）。  
- 洋葱皮预览。  
- 保证 packed sheet 与 Aseprite 装箱结果同一布局（算法可不同，元数据正确即可）。
