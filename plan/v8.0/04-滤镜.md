# 04 · 滤镜

> 日期：2026-11-02（Asia/Shanghai）  
> 状态：**已完成**（2026-11-02 Asia/Shanghai；P1 卷积/中值/曲线仍后续）  
> 证据：P0 outline/replace/hue-saturation + invert/brightness-contrast；CLI `ase filter hue-saturation`；Indexed hue 走 RGBA 光栅化

## 1. 背景

`filters-lib` 本地链接 `laf-base`、`laf-gfx`、`doc-lib`，实现图像效果。无头对齐方式：每个滤镜 = 纯函数 `(Image, params, target mask) → Image`，再挂 CLI。

## 2. Aseprite 对应模块（完整列表，本地 `filters/*.h`）

| 滤镜 | 头文件 | 无头优先级 |
|---|---|---|
| Outline | `outline_filter.h` | P0（像素画高频） |
| Replace color | `replace_color_filter.h` | P0 |
| Hue/Saturation | `hue_saturation_filter.h` | P0 |
| Invert | `invert_color_filter.h` | P1 |
| Brightness/Contrast | `brightness_contrast_filter.h` | P1 |
| Convolution matrix | `convolution_matrix*.h` | P1 |
| Median | `median_filter.h` | P1 |
| Color curve | `color_curve*.h` | P2 |
| 基础设施 | `filter.h`、`filter_manager.h`、`target.h`、`tiled_mode.h`、`neighboring_pixels.h`、`filter_indexed_data.h` | 实现支撑 |

**不做**：滤镜对话框 UI、预览窗、互动式曲线编辑器。

## 3. 目标

1. `pxl-ase-filters`（或模块）实现上表 P0–P1。  
2. Indexed 与 RGBA 路径都可用；Indexed 优先查表/索引安全。  
3. CLI：`step-300 ase filter <name> [params] --layer ...`；或批处理 flags（若公开 CLI 无直接滤镜 flag，则用子命令扩展，**不假装**官方已有同名 flag）。  
4. Outline 与现有 `pxl-core::paint_outline` / Op `Outline` **语义对照**：能复用则复用，差异写进测试名。

## 4. 非目标

- 复制 convolution 预设 XML 资源从 Aseprite `data/`。  
- 保证与 C++ 逐像素一致。  
- GPU 滤镜。

## 6. 工作包 / 里程碑

### M4F.0 — 滤镜 trait 与 target

- `target`：全图 / 选区 / 索引色约束；对齐 `target.h` 概念而非代码。  
- **验收**：两个假滤镜（noop、invert）跑通 harness。

### M4F.1 — P0：Outline / Replace / HueSat

- Outline：圆角/方角、处在外/内；与 `OutlineMode` 映射表。  
- Replace：from/to + tolerance。  
- HueSat：HSV 调整；Indexed 走 palette 条目或光栅化策略二选一（冻结在任务书）。  
- **验收**：每个滤镜 ≥3 夹具；Indexed 不引入意外新色（除非允许）。

### M4F.2 — P1：Invert / BrightnessContrast / Convolve / Median

- 卷积：内置少量矩阵（identity、sharpen、blur）；用户 JSON 矩阵可选。  
- **验收**：奇异核拒绝；median 半径上限。

### M4F.3 — P2：Color curve

- 可后置；不阻塞 M7 CLI 主线。  
- **验收**：若未做，矩阵标「后续」而非 PASS。

### M4F.4 — 接入目标选择器

- 与 03 共用 layer/frame/tag 过滤。  
- **验收**：隐藏层默认跳过。

## 7. CLI 形态（扩展，非假冒官方 flag）

官方公开 CLI **没有** `--outline-filter` 一类开关（核实 `app_options` / 公开文档）。因此：

```text
step-300 ase filter outline --width 1 --mode outside -i in.aseprite -o out.aseprite
step-300 ase filter replace --from '#ff0000' --to '#00ff00' --tolerance 0 ...
```

批处理脚本需要滤镜时走子命令；`--batch` 官方开关用于「不启动 UI」语义，我们的 `ase` 默认即无 UI。
