## 1. 背景

Aseprite 将 **帧** 与 **层** 正交；Tag 标记帧区间（Walk/Run）；Slice 标记空间区域（可随帧变 keys）；Cel 可跨帧链接以省空间。公开 CLI 大量旗标依赖这些概念。现有 `pxl-format::Anim` / recipe anim / `sheet` 的 `frameTags` 能表达**导出后**的标签，但不是编辑文档里的一等时间轴。

## 10. 附录：帧编辑时 Tag 边界算法（草案）

设 Tag 闭区间 `[from, to]`（0-based），删除帧 `i`：

1. 若 `i < from`：`from -= 1; to -= 1`  
2. 若 `from ≤ i ≤ to`：`to -= 1`；若结果 `to < from` 则删除该 Tag 或标警告（冻结：删除 Tag）  
3. 若 `i > to`：不变  

插入帧于位置 `i`（新帧占据 `i`，旧 `≥i` 右移）：

1. 若 `i ≤ from`：`from += 1; to += 1`  
2. 若 `from < i ≤ to`：`to += 1`（Tag 变长）  
3. 若 `i > to`：不变  

实现必须单测这六条。导出 `--frame-range from,to` 使用同一闭区间约定，并在 help 写明。

## 11. 附录：Slice key 选择

对帧 `f`，取 `keys` 中 `frame ≤ f` 的最大 `frame` 对应 key；若不存在，取第一个 key 或报错（冻结：报错，避免静默用错 pivot）。

## 12. 与 `MAX_ANIM_FRAMES` 的冲突处理

`pxl-core` 常量 16 约束 recipe/Anim 路径。`AseDoc` 允许更大。桥接策略（冻结建议）：

- `ase import --recipe-bridge` 默认：`frame_count > 16` → 错误 `E_ANIM_LIMIT`；  
- 显式 `--truncate-frames 16` 才截断并写 warning 到 manifest。
