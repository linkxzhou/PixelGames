# 06 · 文件格式 I/O

> 日期：2026-11-02（Asia/Shanghai）  
> 状态：**已完成**（2026-11-02 Asia/Shanghai）  
> 证据：`libs/pxl-ase-io` 读/写；roundtrip 测试；自造 fixture
> Aseprite 对应：`src/dio/`（Document IO，本地 MIT LICENSE + README 称 decode Document；encoder 文件亦存在）；公开规格 `docs/ase-file-specs.md`；`src/app/file/*_format*` 注册多格式；`src/flic/`、`src/tga/`、`src/psd/`  
> **法律**：按公开规格 clean-room 实现；不复制 `dio/*.cpp` / `app/file/*.cpp` 源码进产品

## 1. 背景

没有可靠的 `.aseprite` 读写，文档模型只是空壳。公开规格描述 Header（magic `0xA5E0`）、Frame、Chunk 类型与像素布局（RGBA/Gray/Indexed、zlib）。本地 `dio` 含 `aseprite_decoder.*`、`aseprite_encoder.*`、`detect_format.*` 等——**仅作接口存在性证据，实现必须 clean-room**。

现有 steps 侧：`pxl-export` 读写 PNG/GIF；`sheet_json` 写 hash JSON；**无** `.ase` 二进制编解码（`rg` 仅注释/文案级提及 Aseprite）。

## 3. 目标

1. `pxl-ase-io`：探测 → 解码 → `AseDoc`；编码反向。  
2. 支持色深 32/16/8；层、cel（含链接）、palette、tags、slices、frame duration 的往返（golden）。  
3. zlib 像素块按规格。  
4. `--oneframe` 只载第一帧（对齐公开 CLI）。  
5. 错误：损坏文件、不支持 chunk → 明确码；未知 chunk 策略（跳过 vs 失败）冻结。  
6. 绝不把第三方源码生成物勾进 `include!`。

## 4. 非目标

- 加密/专有扩展 chunk 全覆盖。  
- 保证与历史每一个 Aseprite 小版本 bit-identical 重写。  
- 在 IO 层做 UI 进度条。

## 6. 工作包 / 里程碑

### M2.0 — 规格切片与 golden 计划

- 列出要实现的 chunk 白名单（层、cel、palette、tags、slices、色板等）。  
- 准备自绘最小 `.aseprite` 夹具（**用官方编辑器手工导出的小文件可作为只读测试输入**；仓库是否提交二进制夹具由维护者定，计划允许 `testdata/`）。  
- **验收**：白名单表进本文件附录；夹具获取步骤成文。

### M2.1 — Decoder MVP

- Header + 帧循环 + 图像 cel + 全局 palette。  
- **验收**：夹具尺寸/色深/帧数断言；像素 sha256 稳定。

### M2.2 — Tags / Slices / Layer 组

- **验收**：与 `--list-tags`/`--list-slices`/`--list-layer-hierarchy` 期望一致（字符串级）。

### M2.3 — Encoder MVP

- 写出可读回的子集；外部 Aseprite 打开属**人工**验收项 → 记 `NOT_ASSESSED` 直至有人打开确认。  
- **验收**：自产自消往返；人工项单独勾选。

### M2.4 — 多格式门面

- `open_any(path)`：按扩展名/探测分派；PNG 单帧升为单层文档。  
- **验收**：png/gif/ase 各一。

### M2.5 — 与 `PxlDoc` 导入

- **验收**：导入后 `step-300 inspect` 可读。

## 7. Clean-room 纪律（强制）

1. 实现者可阅读：`docs/ase-file-specs.md`、公开博客/社区格式说明、**本仓库计划**。  
2. 实现者避免：对着 `dio/aseprite_decoder.cpp` 逐行翻译。接口名以 Rust 习惯重建。  
3. 代码评审检查：diff 中是否出现从 thirdparty 粘贴的独特注释/标识符串。  
4. EULA 提醒：个人可编译参考源码，**产品分发不得夹带** Aseprite 程序或专有资源。

## 8. 验收

- 解码模糊测试（可选后期）：随机截断不崩溃。  
- CI 可跑无图形依赖。  
- 未跑：`NOT_ASSESSED`。

| 风险 | 缓解 |

| 误复制源码 | §7 纪律 + 评审 |
