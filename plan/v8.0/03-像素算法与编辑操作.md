# 03 · 像素算法与编辑操作

> 日期：2026-11-02（Asia/Shanghai）  
> 状态：**部分完成**（2026-11-02 Asia/Shanghai）  
> 证据：`pxl-ase::ops::apply_op_to_frame` 桥接 `pxl-ops`
> Aseprite 对应：`src/doc/algorithm/`（flip、floodfill、rotsprite、resize、shift、polygon、selection…）；`src/doc/brush*`；部分 `src/app/commands/cmd_*.cpp` 的无头可复述语义  
> steps 对应：`pxl-format::Op`、`pxl-ops`、`step-300 op` / `anim`

## 1. 背景

GUI 里的画笔、选区、填充在无头世界应变为 **可序列化操作**。PixelGames 已有成熟 Op DSL（`pxl-format/src/ops.rs`）与执行器（`pxl-ops`），宏动画（`MACRO_NAMES`）覆盖行走/受击等。Aseprite 对齐需要：

1. 把文档级目标（某层、某帧范围、某选区）接到 Op；  
2. 补齐 flood fill、选区修改、画布裁剪等缺口；  
3. 明确「不实现交互式笔刷引擎」。

## 2. Aseprite 对应模块（路径）

`thirdparty/aseprite/src/doc/algorithm/` 本地文件包括（节选）：

- `flip_image.*`、`flip_type.h`
- `floodfill.*`、`fill_selection.*`、`stroke_selection.*`
- `rotate.*`、`rotsprite.*`
- `resize_image.*`、`shrink_bounds.*`
- `shift_image.*`
- `polygon.*`、`modify_selection.*`

另有 `doc/brush.h`、`brush_type.*`（笔刷形状）；CLI 批处理以几何/滤镜/变换为主，**不**实现压感采样环。

`app/commands` 中无头可借鉴语义的例子：`cmd_flip`、`cmd_crop`、`cmd_canvas_size`、`cmd_clear_cel`、`cmd_flatten_layers`、`cmd_color_quantization`（量化归 02）、`cmd_export_sprite_sheet`（归 05/08）。大量 UI 命令（`cmd_keyboard_shortcuts`、`cmd_fullscreen_*`）跳过。

## 3. 目标

1. 扩展或映射 Op，使 `AseDoc` 目标可表达：`target: { layer, frames, region }`。  
2. 补齐：**flood_fill**、**selection expand/contract/invert**（矩形/色键先做）、**canvas_size**、**crop_sprite**。  
3. 变换类与现有 `Flip`/`Rotate90`/`Rotate`/`Shift`/`Shear`/`Squash` 对齐语义并测回归。  
4. `step-300 op` 继续服务 `PxlDoc`；新增 `step-300 ase op` 或 `ase --script-like ops.json`（见 08）作用文档。  
5. 宏：可对文档帧范围展开，复用 `pxl-ops::expand_macro`。

## 4. 非目标

- 实时笔刷、对称绘画工具 UI、自定义 brush 位图市场。  
- 非线性 undo 浏览器。  
- 保证与 `doc/algorithm/*.cpp` 像素级一致；以测试向量与属性测试为准。

## 7. DSL 策略

**优先扩展 `pxl-format::Op`**（单一 DSL），为文档批处理加「寻址包装」：

```json
{ "target": { "layer": "Body", "frames": [0, 3] }, "op": { "op": "flip", "axis": "x" } }
```

若担心 `deny_unknown_fields` 影响旧配方，寻址包装放在 `ase` 命令的外层 JSON，内层仍是现有 `Op`。

## 8. 验收

- 夹具：3 帧双层精灵，对 Body 层 frame-range 翻转，Background 不变。  
- 性能：256×256、16 帧内在约定预算内（具体数字 M0 定）。  
- 未跑检查 = `NOT_ASSESSED`。

## 9. 风险

- Linked cel 误复制导致文件膨胀 → API 默认共享。  
- 与 `pxl-art` enhance 管线职责重叠 → enhance 保持「单帧升采样」；ase op 保持「文档编辑」。
