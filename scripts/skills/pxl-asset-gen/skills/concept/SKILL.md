# Concept-first

Drawing from nothing asks one pass to invent identity, pose, camera, and every pixel. Split design from pixel craft.

## Procedure

1. **Art notes** from the brief: proportions, 3–5 landmarks, material list (metal/cloth/skin), forbidden details at this size.
2. **Optional reference.** If the user supplies art or asks for a concept image, treat it as **mass and pose guidance only**. Never downscale a photo/concept straight onto the pixel grid as final art (mush + fake AA).
3. **Mass map.** Name 3–6 colour masses → palette indices (see palette skill). Example: `body→3, shade→4, outline→1, eye→7`.
4. **Storyboard (animation only).** List key poses as words or tiny ASCII thumbnails; frame count target (e.g. walk 4–6).
5. Continue to `new` / `draw`. The mass map is the draw plan.

## What this must not do

- Paste or depend on third-party Aseprite extension prompts/schemas.
- Claim pixels came from an image model — pixels still come only from `$PXL`.
