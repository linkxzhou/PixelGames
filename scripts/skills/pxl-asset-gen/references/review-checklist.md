# Review checklist

Mark each: PASS / FAIL / NOT_ASSESSED.

## Mechanical

- [ ] `step-300 validate` exit 0 (or documented override)
- [ ] `inspect` size matches brief
- [ ] Palette count within budget; no surprise off-palette (indexed)
- [ ] Animation tags/ranges correct (`ase list-tags` / recipe anim names)

## By eye

- [ ] Cold-read sentence names the subject
- [ ] Silhouette readable at 1×
- [ ] Clusters deliberate; no salt-and-pepper noise
- [ ] No pillow shading unless intended
- [ ] Outline selective; no mud halo
- [ ] Light direction consistent
- [ ] Accent colours sparse and purposeful
- [ ] Frames loop without a pop (if animated)

## Delivery

- [ ] Export paths exist; scaled screenshot prepared for the user
- [ ] No edits under `games/`
